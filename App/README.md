# NoviaGen App

Flutter frontend for NoviaGen, a local-first generative media application.

## Getting Started

Run commands from this directory:

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

If a project-local Flutter SDK exists, use `../tools/flutter/bin/flutter` instead of a global `flutter`.

See `doc/ARCHITECTURE.md` and `doc/TOOLS.md` for project-specific guidance.
